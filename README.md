# Civic & Multipurpose — a GigKit site template

Structured and dependable — a slate, stone and amber palette with a Source Serif masthead and a clean grid. For civic halls, multipurpose and town venues.

An official **[GigKit](https://gigkit.site)** venue template. In the GigKit admin, pick it from the template gallery to use as-is (your site tracks this repo and gets updates automatically), or fork it to make it your own.

Content — events, news, your venue details, hero image and strapline — is edited in the GigKit admin, not in this repo. This repo holds the design (Liquid templates binding to `site.data`).
